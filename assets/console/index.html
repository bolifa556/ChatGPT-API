使用说明

  1. 填写 API 地址与 Key，启用来源并保存。
  2. 在“模型与上下文”点击“刷新模型目录”查看模型；启动 API 入口时也会获取目录，运行期间不定时刷新。
  3. 保存后，完全退出客户端并重新打开入口。

启动入口

ChatGPT / ChatGPT 官方
使用原生登录和官方模型，兼容用过 API 模型的对话历史。
chatgpt-api
已登录时显示官方与 API 模型；未登录时只使用 API。
chatgpt-apionly
始终使用自定义 API。Linux 只提供此类入口。

图片与上下文

在“模型与上下文”的图片模型行勾选“默认生图”，取消后恢复自动选择。多个来源有同名模型时，会显示来源名称并分别路由。上下文设置只影响 API 模型，已确认的容量会缓存。

功能限制

模型自身能力和原生工具的账号要求仍然有效。混合模式中，官方额度耗尽后即时切到 API 模型仍可能被原生输入框拦截，当前适配层无法解除这一限制。官方与 API 切换后的压缩方式需退出重开才能同步。
