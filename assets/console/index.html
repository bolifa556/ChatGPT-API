ChatGPT API/API 来源

API 来源

模型与上下文

官方生图设置使用已登录订阅账号的生图服务，原样转发官方请求，不使用下方的模型和强度设置。

自定义生图设置使用下方勾选的默认生图模型，并应用该模型的思考与画质设置。

纯 API 入口或未登录时，始终使用自定义生图。这里只决定生图请求的去向，不改变聊天模型。

模型来源

模型可接收的最大上下文长度，对十个档位（32K、64K、128K、256K、384K、512K、640K、768K、896K、1M）分别进行请求测试，选取通过的最大容量作为已知容量，支持手动修改。

左侧为配置的上下文窗口，右侧为 Codex 扣除预留空间后的显示值。通常预留 5%，例如 500K → 475K，支持手动修改。

模型可用的思考强度，对low / medium / high / xhigh / max 五个档位分别进行请求测试，选取通过的思考档位作为可用思考档位，支持手动修改。
尚未发现模型。添加 API 来源并保存后会自动检测。

使用说明

  1. 填写 API 地址与 Key，启用来源并保存。
  2. 新增来源保存后会自动检测模型。可在“模型与上下文”查看结果或手动刷新目录。
  3. 保存后，完全退出客户端并重新打开入口。

启动入口

chatgpt-official
使用原生登录和官方模型，保留官方远程压缩。默认兼容两个 API 入口创建的对话。
chatgpt-api
已登录时显示官方与 API 模型；未登录时只使用 API。
chatgpt-apionly
始终使用自定义 API。Linux 只提供此类入口。

图片与上下文

系统会自动选好默认生图模型，首次无需手动设置。可在“模型与上下文”更换，取消手动勾选可恢复自动。多个来源有同名模型时，会显示来源名称并分别路由。上下文设置只影响 API 模型，已确认的容量会缓存。

账号与 Fast

纯 API 入口不需要登录官方账号，聊天和生图使用自己的 API。支持 Fast 的 GPT 模型可在客户端点击小闪电，实际是否加速取决于服务商；非 GPT 模型不显示这个开关。

对话与压缩

三个入口自动兼容本机已有对话，无需选择历史通道。运行期间临时统一通道标记，退出后恢复；保留原对话、消息和项目。官方入口选择官方模型，纯 API 入口选择自定义模型。两个 API 入口使用原生文本压缩，官方入口使用原生远程压缩。官方加密压缩内容不能由其他厂商模型解密。

功能限制

模型自身能力和原生工具的账号要求仍然有效。混合入口按当前模型区分额度。官方额度耗尽后，选择自定义 API 模型可在原对话继续发送，使用该来源自身的额度。
