使用说明

  1. 填写 API 地址与 Key，启用来源并保存。
  2. 在“模型与上下文”点击“刷新模型目录”查看模型；启动 API 入口时也会获取目录，运行期间不定时刷新。
  3. 保存后，完全退出客户端并重新打开入口。

启动入口

ChatGPT / ChatGPT 官方
使用原生登录和官方模型，保留官方远程压缩。默认兼容两个 API 入口创建的对话。
chatgpt-api
已登录时显示官方与 API 模型；未登录时只使用 API。
chatgpt-apionly
始终使用自定义 API。Linux 只提供此类入口。

图片与上下文

系统会自动选好默认生图模型，首次无需手动设置。可在“模型与上下文”更换，取消手动勾选可恢复自动。多个来源有同名模型时，会显示来源名称并分别路由。上下文设置只影响 API 模型，已确认的容量会缓存。

账号与 Fast

纯 API 入口保留已有 ChatGPT 登录，让项目、偏好和工作区沿用原账号，模型请求仍只走自定义 API。已登录且所选 GPT 模型支持时，使用客户端的小闪电；未登录时保留原生客户端的界面限制，控制台不设置第二个速度开关。

对话与压缩

三个入口自动兼容本机已有对话，无需选择历史通道。运行期间临时统一通道标记，退出后恢复；保留原对话、消息和项目。官方入口选择官方模型，纯 API 入口选择自定义模型。两个 API 入口使用原生文本压缩，官方入口使用原生远程压缩。官方加密压缩内容不能由其他厂商模型解密。

功能限制

模型自身能力和原生工具的账号要求仍然有效。混合模式中，官方额度耗尽后即时切到 API 模型仍可能被原生输入框拦截，当前适配层无法解除这一限制。
