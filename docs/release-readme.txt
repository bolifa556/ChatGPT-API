ChatGPT API 3.1.7 — Windows x64

安装
1. 安装官方 ChatGPT/Codex 桌面客户端。
2. 从托盘完全退出客户端，完整解压 ZIP，运行“安装.cmd”。
3. 选择独立的程序安装目录，填写 API 基础 URL 和 Key。
4. 从桌面 ChatGPT、chatgpt-api、chatgpt-apionly 启动。

入口
ChatGPT：官方登录与官方模型，保留混合历史兼容通道。
chatgpt-api：有官方登录时显示官方与 API 模型，未登录时只用 API。
chatgpt-apionly：始终使用 API，模型与图片请求不回退官方。
切换入口前完全退出客户端；原生登录与聊天记录共用并保留。

控制台
打开程序安装目录中的“控制台.vbs”。
可添加多个 API URL / Key，启用来源，刷新模型目录，设置图片模型和上下文。
保存 API 来源后，在“模型与上下文”页右上方点击“刷新模型目录”。
已保存的 Key 显示为密码圆点，点击眼睛可显示或隐藏。修改其他设置不会覆盖 Key。来源名称旁可点击“重命名”，旧配置自动导入为“默认 API”。
保存后完全退出并重新打开客户端，加载新的来源、菜单和上下文。
每次 API 入口启动获取全部启用来源；运行期间不定时轮询。
相同模型名按来源分开，使用各自的地址与 Key，不自动跨来源切换。

上下文与图片
API 默认全局上限 500,000 tokens，客户端通常预留 5%，有效显示约 475k。
较小模型取实际容量；已确认容量缓存，控制台可调整全局与单模型上限。
官方模型仍按原生目录。浮窗随客户端的新一轮统计刷新。
图片模型在“模型与上下文”中显示，容量和上限留空，在“当前配置”勾选“默认生图”。只可设置一个默认，取消后自动选择；默认图片模型不改变聊天模型与 API 来源优先级，仍需上游提供兼容 Images 接口。当前原生工具不支持在聊天文字中可靠切换图片模型。
无对应能力时明确报错。混合模式已设置默认 API 生图模型时直接使用该模型；未设置时，有官方登录则先尝试官方，明确不可用后可回退 API。

功能与限制
保留原生指令、工具、历史及输出，仅转换协议，不添加任务提示词或聊天内容。
支持 Responses/Chat、流式响应、response.interrupt 与 Fast 档位传递。
模型生成、压缩、生图不设置适配层响应等待上限；不增加网络重试或修改代理/TUN。
模型、原生客户端或工具缺少的能力不会补齐。要求官方身份的浏览器/在线工具不能用 API Key 替代账号。
混合模式官方额度用尽后，输入框可能在发送前拦截；即时切 API 模型不保证解除，此限制尚未修复。
官方/API 切换后的压缩方式需退出重开同步；不可解密的官方压缩块不能保证跨厂商续聊。

更新与数据
默认程序目录：%LOCALAPPDATA%\Programs\ChatGPT-API-Launcher
安装器会识别现有桌面入口。更新选择原目录，保留 data 和其他用户文件。
安装后可删除发布包解压目录，不要删除程序安装目录。
程序包含 Node.js 与依赖，运行时准备无需下载；模型服务仍需网络。
data/providers.json 保存多来源、明文 Key 和上下文；data/.env 保留兼容启动配置。
不要分享安装后的 data，只分发原始 ZIP。包内不含个人 Key、登录、聊天、缓存或日志。

包内：安装.cmd、使用说明.txt、setup、payload、内部逐文件安装清单 release.json。
各版本独立存放于 release/<版本>/，没有独立下载校验文件。
本项目为第三方工具，不含官方客户端安装程序，品牌与依赖权利归原权利人。

安装时可选择“跳过，稍后配置”，保留已有 API 设置；首次空配置安装不请求模型目录。API 入口在未配置时给出明确提示，可稍后打开控制台填写。Linux 终端安装另可使用 ./install.sh --skip-api。Windows / macOS 的官方入口不要求填写 API。
