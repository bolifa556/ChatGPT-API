ChatGPT API Launcher — Windows x64 独立安装包

使用方法
1. 先安装官方 ChatGPT/Codex 桌面应用。
2. 从托盘完全退出 ChatGPT，解压整个 ZIP，不要直接在压缩包里运行。
3. 双击本目录的“安装.cmd”，选择安装目录，点击“安装并配置”。
4. 在配置界面填写 API 基础 URL 和 API Key，点击“安装 / 更新”。
5. 从桌面上的 ChatGPT、chatgpt-api 或 chatgpt-apionly 快捷方式启动。

安装与更新
安装器会优先识别已有桌面入口的安装目录；首次安装默认使用：
%LOCALAPPDATA%\Programs\ChatGPT-API-Launcher
更新已有安装时请选择原目录，程序文件会更新，data 中的已有配置和数据会保留。
安装完成后可删除解压的发布包目录；不要删除选定的程序安装目录。
本包已携带 Node.js 和运行依赖，准备运行环境不需要联网下载。
安装时检查模型列表、使用官方账号或网关模型仍需要相应网络连接。
官方模型目录按当前已安装的原生内核版本刷新，不固定在启动器发布时的模型列表。
更新客户端或启动器后，从托盘完全退出并重开一次，加载最新官方与网关模型菜单。

三个入口
ChatGPT：保留原生登录，只使用官方模型，保留混合历史的兼容通道。
chatgpt-api：使用配置的网关；有官方登录时同时显示官方模型。
chatgpt-apionly：不管是否保存官方登录，模型目录、模型请求及生图只使用网关。
三个入口使用同一份原生客户端和聊天记录，不删除官方登录，也不改写聊天正文。
模型目录由各入口对应的实际来源提供，不另外维护模型隐藏名单；网关的 GPT 模型正常可用。
在同一对话切换官方/网关模型后，目前需要完全退出并重开，才能同步提供方及压缩方式。
安装器不更新原生客户端，不会修改其登录文件、语言设置或聊天正文。

生图与编辑
ChatGPT 入口只使用官方生图，失败保留官方错误。
chatgpt-api 有官方登录时优先使用官方生图；官方明确不可用时回退到 API 生图模型。
chatgpt-api 未登录时及 chatgpt-apionly 始终只使用 API 生图模型；API 没有对应模型时直接报错。
支持非 GPT Image 模型。可从 API 模型元数据和已知生图名称自动识别；任意别名可在
安装目录 data\.env 设置 IMAGE_MODEL=模型ID，编辑可另外设置 IMAGE_EDIT_MODEL=模型ID。
这些 ID 必须在当前 API 的模型列表中。网关需提供 OpenAI 兼容 Images 接口。
默认使用 JSON 图片编辑；旧网关只支持表单时可设置 IMAGE_EDIT_FORMAT=multipart。
网络错误、临时限流、内容拒绝、参数错误不会触发重新生图，不增加网络重试。

Fast：保留请求的服务档位，以及上游实际返回的档位。自定义模型没有声明速度档位时，不复制官方倍速描述。
浏览器：使用原生工具；模型转发代理与工具自身出网是独立链路。无官方登录时，原生扩展浏览器的官方身份接口可能不可用。
发布包不修改系统代理模式、TUN、DNS 或原生浏览器插件。纯 API 模式的本地工具和文本压缩不需要官方凭据。

包内文件
安装.cmd：安装入口。
使用说明.txt：本说明。
setup：安装程序。
payload：待安装的程序及运行依赖。
release.json：版本与逐文件 SHA-256 校验清单。
ZIP 同目录的 .sha256 文件可用于核对整个下载包是否完整。

发布包不包含 API Key、个人配置、聊天记录、运行缓存、日志和测试结果。
安装后，API Key 保存在所选程序目录的 data\.env；分享时请分享原始 ZIP。
此包只包含启动器，不包含官方 ChatGPT/Codex 客户端安装程序。
