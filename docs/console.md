# 本地控制台

控制台随 3.1.5 程序安装，使用包内 Node 与系统浏览器，无需新增依赖。

| 平台 | 入口 |
| --- | --- |
| Windows | 安装目录 `控制台.vbs` |
| Linux | 安装目录 `控制台.desktop`、`linux/console`，或应用菜单“ChatGPT API 控制台” |
| macOS | `chatgpt-console.app`，或程序目录 `控制台.command` |

## API 来源

每个来源分别保存名称、基础 URL、Key、启用状态和图片模型选项。地址支持 HTTP / HTTPS，省略 `/v1` 时自动补齐；不能包含账号密码、查询参数或片段。最多配置 32 个来源，至少保留一个启用来源。旧 `.env` 自动导入为“默认 API”，只在保存时生成 `data/providers.json`。

保存过的 Key 不回显；输入框留空表示不修改，眼睛按钮只切换新输入文字的显示。删除来源不会删除聊天。重新添加会得到新的稳定标识，旧对话中的模型应在客户端中重新选择。

“刷新模型目录”只向已保存且启用的来源请求 `/models`。有未保存修改时先保存或放弃；不会把草稿地址或 Key 发出去。目录在每次 API 入口启动时也会加载，没有后台定时轮询。一个来源失败不阻断其他来源；匹配同一 URL / Key 的 24 小时内缓存可作为降级目录，页面会标明缓存或错误。

## 上下文

全局上限默认 500,000 tokens，可设置为 4,096 至 2,000,000；单模型上限留空为自动。最终容量取单模型选择、已知实际容量和全局上限中的较小值。未知实际容量时使用兼容模板，手工填写不能证明上游支持该数值。

已确认容量按基础 URL / 原始模型 ID 缓存，目录刷新不额外进行容量生成测试。预计可用值按客户端模板的预留比例计算，通常 500k 对应 475k；官方模型沿用官方目录，不受控制台的 API 上下文设置影响。

## 图片模型

展开来源的“图片模型”，可填写该来源 `/models` 中的准确模型 ID。留空自动识别。编辑模型留空时沿用生图设置；旧接口可选择 Multipart，否则保留 JSON。“优先生图来源”调整自动候选的优先顺序，不让普通聊天请求跨来源回退。

## 保存与生效

保存会写入本安装目录的配置，不关闭客户端、不改原生聊天。模型菜单、来源与上下文需在完全退出客户端并重新打开对应入口后生效。控制台中的刷新结果不代表运行中的原生菜单已经重载。

同时编辑时使用修订号防止覆盖另一窗口的保存。控制台只监听随机的 `127.0.0.1` 端口，校验连接令牌、Host 与 Origin，不开放远程管理。关闭页面不终止聊天；“关闭控制台”仅停止控制台服务。

Key 以明文保存在本机配置文件，尚无系统钥匙串加密。不要分享 `data/`，对外分发原始发布包。
