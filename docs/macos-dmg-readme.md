# ChatGPT API 3.1.6 — macOS

Apple Silicon / ARM64 单文件 DMG，包含三个聊天入口与一个控制台 App。需要先安装官方 `ChatGPT.app`，本包不包含或修改官方客户端。

| App | 用途 |
| --- | --- |
| `chatgpt-official.app` | 原生登录与官方模型，保留混合历史兼容 |
| `chatgpt-api.app` | 已登录时合并官方与 API 模型，未登录时只用 API |
| `chatgpt-apionly.app` | 无论是否登录，模型与图片请求只使用 API |
| `chatgpt-console.app` | 管理 API 来源、模型目录、图片模型和上下文 |

聊天入口采用已核对的官方 macOS 图标资源。官方兼容入口与本体不同名，不会覆盖 `ChatGPT.app`。

## 安装

1. 完全退出官方客户端（Command-Q）。
2. 打开 `ChatGPT-API-Provider-3.1.6-macos-arm64.dmg`。
3. 将需要的 App 拖入“应用程序”。
4. API 入口首次填写 URL 和 Key，支持 Command+V 和“粘贴”按钮；官方入口无需 API Key。
5. 日常从相应入口启动；切换入口前完全退出客户端。

包内已带 Node.js ARM64 与依赖，无需 Node、npm 或 Python。启动器运行时要求 macOS 13.5 或以上，官方客户端要求以其安装版本为准。

## 安全提示与权限

本包使用 ad-hoc 签名，未使用 Apple Developer ID，未经过 Apple 公证。提示“无法验证开发者”或“Apple 无法检查恶意软件”时，按“系统设置 → 隐私与安全性 → 仍要打开”正常允许。参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。DMG 格式本身不能消除该提示。

聊天入口声明麦克风、摄像头、系统音频、自动化与相关文件访问用途；声明不会主动申请权限。实际使用 Dot 通话、自动化、屏幕录制或电脑控制时，按系统与原生助手提示授权。更新后 ad-hoc 签名的身份可能变化，部分权限可能需重新确认；不需要重置全部权限或授予全盘访问。

入口通过 LaunchServices 启动官方客户端，保留原来的 `CODEX_HOME`、登录与聊天位置，不直接执行客户端主程序，不改签官方客户端。

## 控制台与设置

打开 `chatgpt-console.app`。多个 URL / Key 可同时启用；点击“刷新模型目录”查看结果，启动 API 入口时也会获取所有来源，不定时轮询。保存后退出并重开客户端，加载新菜单与上下文。

默认 API 窗口上限 500,000 tokens，通常显示 475k；较小模型取实际容量。单模型和全局上限可在控制台调整，已确认容量会缓存；官方模型仍按原生配置。

每个来源的“图片模型”中可指定准确模型 ID、编辑格式及优先来源。无登录或 API-only 直接使用 API；混合模式有官方身份时优先官方，明确不可用才回退 API。没有对应能力时明确报错。

## 数据与更新

四个 App 共用程序目录：

```text
~/Library/Application Support/chatgpt-apionly
```

多来源配置与 Key 在 `data/providers.json`；`data/.env` 保留兼容配置。两者均为明文并限制当前用户读写，不放入 App 本体。程序目录另有 `控制台.command`，日常可直接使用控制台 App。

原生聊天、登录、插件仍由客户端管理。启动期间临时接管路由和模型目录，客户端退出后恢复；其他同时使用相同 `CODEX_HOME` 的 CLI 可能读到临时配置。三个聊天入口分别记住模型选择。

更新前 Command-Q 退出客户端，替换“应用程序”中的入口和控制台 App，保留上述数据目录。分享时仅分发 DMG，不分发已填写密钥的程序目录。

## 已知边界

- 官方额度用尽后，混合模式输入框可能在发送前拦截；即时选 API 模型不能保证解除，当前未修复原生 provider 的同步限制。
- 官方 / API 模型切换后的压缩 provider 需要退出重开同步。只有不可解密的官方压缩块时，非 GPT 模型无法无损续聊。
- 浏览器扩展、部分插件或在线工具仍可能需要官方身份；API Key 不能替代账号权限。模型或原生客户端缺少的能力不做模拟。
- 不新增提示词或聊天正文，不添加网络重试，不改变系统代理或 TUN。
- 自动验证覆盖打包、签名资源、配置与消息路由；真实 Mac 的图形窗口、TCC、Keychain 与 Gatekeeper 需实机确认，不能据隔离测试宣称全部正常。

安装时可选择“跳过，稍后配置”，保留已有 API 设置；首次空配置安装不请求模型目录。API 入口在未配置时给出明确提示，可稍后打开控制台填写。Linux 终端安装另可使用 ./install.sh --skip-api。Windows / macOS 的官方入口不要求填写 API。
