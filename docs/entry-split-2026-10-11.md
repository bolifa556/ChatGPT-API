# 三个入口与目录整理

版本 3.0.9，2026-10-11。

| 入口 | 登录处理 | 模型目录与请求 |
| --- | --- | --- |
| ChatGPT | 原生官方登录 | 官方；本地消息转换层用于接续混合历史 |
| chatgpt-api | 检查已保存的官方登录 | 有登录时官方与网关；无登录时网关 |
| chatgpt-apionly | 不使用官方登录作为模型凭据，保留登录文件 | 始终网关，包含网关实际提供的 GPT 模型 |

入口范围应用于 HTTP、WebSocket、目录和生图，而不是维护模型隐藏名单。官方入口不回退到网关生图，也不建立网关 SSH 隧道；混合 API 入口保留原来的官方优先、明确不可用后回退行为；API-only 的图片处理不访问官方文件服务。

三个入口共用客户端和聊天记录。模型切换继续采用原生功能，不添加提示词、用户消息或聊天记录。API 与 API-only 分别保存模型偏好；退出恢复时保留用户其他设置。取 Key 助手使用活动入口记录，避免 API-only 因本机保存了 OAuth 而误用混合路由。

源码、安装器、测试及文档保持各自目录，运行数据仍在 `data/`。Windows/Linux 构建与默认发布测试统一使用 `release/`。原有 3.0.5—3.0.8 的 12 个发布归档及校验文件已迁移并验证完整性；Git 保留原有历史，凭据、缓存、依赖、运行程序与发布二进制不进入提交。

验证记录保存在本机 `data/diagnostics/`。入口范围测试使用隔离上游，检查真实 HTTP/WS 转发、目录来源和凭据保留；它不能代替远端模型能力或网络可用性验证。原生浏览器和语音的客户端扩展未加入本次改动。

本次验证结果：

- 10 组 Node 测试通过，其中包含 225 组跨模型协议组合与三个入口的 5 种登录状态场景。
- Windows 启动器与独立发布包安装测试通过，验证三个快捷方式、配置恢复、独立模型偏好、凭据保留及损坏包拒绝。
- 14 个模型的原生 app-server 切换、工具执行、压缩与恢复测试通过；模型输出来自隔离上游，没有将该结果当作远端模型能力测试。
- Linux x64 与 ARM64 发布包的清单、SHA-256、权限和架构检查通过；x64 包在 WSL Ubuntu 中完成安装、请求转发、工具转换、更新与恢复测试。ARM64 未进行实际运行测试。
- 本机三个桌面快捷方式已同步，操作前后 `config.toml` 与 `auth.json` 的 SHA-256 一致；未启动或重启真实客户端。
- `release/` 内的 15 个归档逐一通过 SHA-256 校验，历史版本没有重新打包。
