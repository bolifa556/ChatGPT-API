## 图片结果兼容修复

- 修复部分 API 在 Responses 中返回 `image_generation_call` 时，原始结果已收到但聊天没有可显示图片的问题。适配层仅转换已有图片，不再次发起生成请求。
- HTTP JSON、SSE 和 WebSocket 使用同一转换逻辑，支持 PNG、JPEG、WebP；处理终态才返回图片、重复事件、多张图片及文字混合的情况。
- 原图保存到客户端数据目录的 `generated_images/chatgpt-api/`，同时保留后续编辑需要的图片内容。文件不放在安装包临时目录，升级或重启路由后仍可读取。
- 图片数据缺失、无效或无法写入本地时明确报错，避免将空白回合当成成功。

本次不新增依赖、MCP、提示词、工具调用或额外聊天，不修改官方客户端。原生 `image_gen` 的 Images 生图/编辑链路、默认生图模型选择和官方通道保持原有行为。

## 验证与边界

回归覆盖协议转换、模型切换的历史保留、图片字节一致性、文件持久保存、错误返回和官方通道透传。在本机官方客户端内核中，已验证兼容图片成为可显示的图片消息，重新载入对话后，原生图片工具能引用原图继续编辑；原有原生生图/编辑链路也通过验证。测试使用隔离配置和本地模拟图片接口，不消耗真实生图额度。

兼容结果以聊天中的图片呈现，不承诺官方图库、进度卡片等专用界面完全一致；其他用户电脑上的原始故障与桌面显示仍需实际使用确认。已有空白历史不会自动重写，更新后需重新发起请求。模型自身能力、API 图片接口权限以及原有跨入口/压缩限制见项目 [README](../../README.md)。

## 安装

完全退出客户端后更新，使用原安装目录并保留 `data/` 与客户端数据目录。Windows / macOS 保留三个聊天入口和控制台；Linux 仅提供 API 入口与控制台。生图模型继续自动选择默认，也可在控制台手动更改。

包内包含运行时和锁定依赖，不含个人 Key、登录、聊天或日志，不提供独立下载校验文件。macOS 仍为 ad-hoc 签名，未经过 Apple 公证，保留系统正常的手动允许流程。
