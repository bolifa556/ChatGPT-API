需要先安装官方客户端。发布包附带运行时和依赖，不含个人配置、Key、登录、聊天、缓存或日志，不附带独立 `.sha256` 文件。混合模式官方额度用尽后的即时切 API 限制仍存在，详见主 [README](../README.md)。
